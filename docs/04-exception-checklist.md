# 예외 처리 체크리스트 (PRD 5장)

상태 값: `미착수` / `진행중` / `완료(미검증)` / `완료(검증됨)`

## 검증 방법 메모

- 5.1~5.3, 5.13: 브라우저에서 직접 입력해 재현 (자동화 불필요, 수동 QA로 충분)
- 5.4~5.7: API 라우트에 인위적 지연/오류를 주입하는 디버그 플래그를 하나 두면 반복 검증이 쉬워진다 (예: `?debug=slow`, `?debug=error`, `?debug=malformed` 쿼리 파라미터로 서버가 의도적으로 해당 상황을 재현)
- 5.12: 브라우저 devtools의 오프라인 모드로 재현
- 5.14: `<script>alert(1)</script>` 등을 실제로 입력해 렌더링 결과가 텍스트로만 보이는지 확인
- 5.18: 두 예외를 동시에 유발할 수 있는 조합(예: 오프라인 + 빈 입력)을 만들어 우선순위대로 문구가 나오는지 확인
